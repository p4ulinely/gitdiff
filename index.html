    Arquivos alterados

      Visualizador de diferenças Git

      Clique em Abrir pasta… e escolha a pasta de um repositório git (a que contém .git). Depois escolha a branch e um commit na lista, ou digite o hash no campo do topo.

      • Tudo roda localmente no navegador. Nenhum arquivo é enviado.
      • Atalhos: j/k próximo/anterior commit, n/p próximo/anterior arquivo.
      • O campo de hash aceita hash abreviado, nome de branch/tag e sufixos como HEAD~3 ou abc123^2.
